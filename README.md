# 🏰 Tower Defense

เกม Tower Defense แบบ 2D ที่พัฒนาด้วย HTML5 Canvas และ JavaScript ล้วนๆ ไม่ใช้ framework ภายนอก

## 🎮 วิธีเล่น

- **วางอุปกรณ์** — คลิกที่ช่องว่างบนแผนที่เพื่อสร้างหอคอย
- **อัพเกรด** — คลิกที่หอคอยที่วางแล้วเพื่ออัพเกรด (สูงสุด Lv.10)
- **ขาย** — คลิกที่หอคอยแล้วกดขายเพื่อรับเงินคืนบางส่วน
- **เริ่มเวฟ** — กดปุ่ม Start เพื่อส่งมอนสเตอร์เข้ามา
- **เป้าหมาย** — ป้องกันไม่ให้มอนสเตอร์ผ่านถึงฝั่งตรงข้าม

## 🗼 อุปกรณ์ (Towers)

| อุปกรณ์ | ราคา | เป้าหมาย | ความสามารถพิเศษ |
|---------|------|----------|----------------|
| **Ballista** | 60 | พื้นดิน + ลอยตัว | ยิงธนู, T2 = 2 ลูก, T3 = 3 ลูก |
| **Torch** | 110 | พื้นดิน | ติดไฟ (Burn DoT) |
| **Cannon** | 180 | พื้นดิน | T1 = ปืนใหญ่, T2 = 2 กระบอก, T3 = ปืนครก |
| **Timewarper** | 140 | พื้นดิน + ลอยตัว | ชะลอความเร็วมอนสเตอร์ |

## 👾 มอนสเตอร์ (Enemies)

| มอนสเตอร์ | ประเภท | HP |
|-----------|--------|-----|
| **Orc** | พื้นดิน | 100 |
| **Fast Orc** | พื้นดิน | 65 |
| **Orc Tank** | พื้นดิน | 450 |
| **Wizard** | พื้นดิน | 160 |
| **Harpy** | ลอยตัว | 90 |
| **Orc Boss** | พื้นดิน | 2000 |

## 🛠️ เทคโนโลยี

- HTML5 Canvas + JavaScript (ES6) ล้วนๆ
- Pseudo-3D rendering ด้วย Radial Gradient
- ไม่ใช้ library ภายนอก
